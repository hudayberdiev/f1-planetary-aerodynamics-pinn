# Translating F1 Ground-Effect Aerodynamics to Planetary Atmospheres

An open-source research project using **Physics-Informed Neural Networks (PINNs)** in PyTorch to evaluate underbody downforce degradation in low-density, high-Knudsen planetary environments (e.g., Mars).

## Tech Stack
- Python 3.10+
- PyTorch (PDE modeling via `autograd`)
- NumPy / Matplotlib

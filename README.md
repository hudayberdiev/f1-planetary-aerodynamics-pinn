# Translating F1 Ground-Effect Aerodynamics to Planetary Atmospheres

An open-source research project leveraging **Physics-Informed Neural Networks (PINNs)** in PyTorch to simulate underbody ground-effect forces in low-density, rarefied gas conditions.

## Tech Stack
- Python 3.10+
- PyTorch (`autograd` for fluid PDEs)
- NumPy / Matplotlib
